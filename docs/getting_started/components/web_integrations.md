## 🔗 Integrations

The Integrations page manages third-party system connections.

✅ What it does:

Manage third-party integrations (e.g., Git, CouchDB), add/edit API keys.   
Add, edit, or delete integrations (e.g., Slack, GitHub, Kafka).   
Manage API keys and credentials.   
Control which tasks or groups use which integrations.   

💡 Example:   

Add a Slack integration for the Oncall task group to send failure alerts.

---

## Frequently Asked Questions

**Q: How do I add a new third-party integration?**
A: Navigate to the Integrations page in the Web UI and click to add a new integration. Provide the required API keys, credentials, and endpoint details for the service (e.g., Slack, GitHub, Kafka). Save the configuration to activate it.

**Q: Can I assign integrations to specific task groups?**
A: Yes. You can control which tasks or groups use which integrations. For example, you can add a Slack integration specifically for the Oncall task group to send failure alerts.

**Q: How do I manage API keys for integrations?**
A: API keys and credentials are managed directly from the Integrations page. You can add, edit, or delete API keys for each configured integration. Keep credentials secure and rotate them periodically.
