## Frequently Asked Questions

### What is EasyTask?
EasyTask is an enterprise workflow orchestration platform that automates, schedules, and manages complex business processes. It provides distributed task scheduling, 40+ pre-built integrations, real-time monitoring, and enterprise-grade security for organizations of all sizes.

### How does EasyTask differ from simple cron or task schedulers?
Unlike basic cron, EasyTask provides a full orchestration platform with dependency management, event-driven triggers, parallel execution, automatic retry and failure handling, load balancing across distributed infrastructure, a web management console, and comprehensive audit trails.

### What industries use EasyTask?
EasyTask is used across finance, insurance, pharmaceutical, accounting, healthcare, and technology industries. It supports compliance requirements with built-in audit trails, role-based access control, and secure credential management.

### Is EasyTask available as a cloud service?
Yes. EasyTask supports both cloud and on-premise deployment models. The cloud version provides managed infrastructure while the on-premise option gives full control over your environment.

### How many integrations does EasyTask support?
EasyTask includes 40+ pre-built integrations covering databases (PostgreSQL, MySQL, Oracle, MongoDB), messaging (Kafka, RabbitMQ), cloud services, CI/CD tools (Jenkins), monitoring (Datadog, Splunk), and business applications (Jira, ServiceNow, Slack).

### Does EasyTask support real-time log viewing?
Yes. EasyTask provides real-time log streaming from all agents and tasks, accessible directly in the web console. You can also browse historical execution logs with filtering, search, and log-level breakdowns to troubleshoot failures quickly.

### Can I run commands on agents without creating a task?
Absolutely. EasyTask's adhoc command execution feature lets you run one-off commands on individual agents or broadcast them across your entire agent fleet — perfect for diagnostics, patches, and emergency operations.

### How does multi-instance scheduling work for load balancing?
You can deploy multiple scheduler instances, each with its own namespace, to partition workloads. Tasks and task groups are assigned to specific instances, enabling horizontal scaling — for example, 10 instances can each handle ~10,000 tasks to manage a total workload of 100K tasks seamlessly.

### Does EasyTask have an AI chatbot or assistant?
Yes. EasyTask includes a built-in AI-powered support chatbot that can create tasks, update schedules, modify configurations, and manage alerting through natural language conversation, reducing manual operations significantly.
